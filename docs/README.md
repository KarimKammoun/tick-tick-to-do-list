# Dossier docs

Tout ce qu'il faut pour démarrer le projet avec un agent de code.

```
docs/
├─ README.md            ← ce fichier
├─ SPEC.md              ← index du cahier des charges + ordre de priorité
├─ PROMPTS.md           ← prompts à donner à l'agent, étape par étape
├─ PROGRESS.md          ← suivi d'avancement (tenu à jour par l'agent)
├─ spec/                ← cahier des charges (5 parties)
└─ design/
   ├─ README.md         ← index des captures avec description
   ├─ android/          ← 13 captures Android (thème clair, français)
   └─ pc/               ← 14 captures PC (thème sombre, anglais)
```

## Comment l'utiliser

1. Copier ce dossier `docs/` à la racine du dépôt (le dépôt peut être vide à part ça).
2. Lancer l'agent de code dans le dépôt.
3. Lui donner le **Prompt 1** de `PROMPTS.md`.
4. Tester, valider, puis donner le prompt suivant.

## Rappel

Ces captures et ce cahier servent de **référence de design et de fonctionnalités**. L'application finale doit avoir son propre nom, logo, icônes et illustrations.
